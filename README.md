# 📍 Outta Boredom (Гео-сервіс підбору локацій)

**Outta Boredom** — це вебдодаток для швидкого та зручного пошуку цікавих місць, закладів і локацій у місті на основі поточного настрою, часу та компанії користувача.

Фронтенд побудований на **React + Vite**, а як Headless CMS використовується **WordPress (REST API)**, розгорнутий на платформі **Pantheon.io**.

---

## ✨ Основні можливості

* 🎯 **Інтерактивний підбір:** Допомагає знайти ідеальне місце за допомогою кількох простих запитань (вайб, бюджет, тривалість, компанія).
* 🗺️ **Мульти-локації:** Підтримка закладів із кількома адресами у місті.
* 📍 **Пряма інтеграція з Google Maps:** Кожне посилання на адресу шукає точну назву закладу для відкриття офіційної картки профілю компанії.
* 📱 **Адаптивний дизайн:** Повністю оптимізовано під мобільні пристрої (кастомний скролінг, зручна навігація, адаптивні блоки).
* ⚡ **Динамічний контент:** Всі дані про місця завантажуються в реальному часі через WordPress REST API & ACF (Advanced Custom Fields).

---

## 🛠️ Технологічний стек

* **Frontend:** React, Vite, JavaScript (ES6+), CSS3 / Tailwind CSS
* **Backend (Headless CMS):** WordPress (Pantheon.io)
* **API:** WordPress REST API + Advanced Custom Fields (ACF)
* **Deployment:** Vercel (Frontend), Pantheon.io (Backend)
